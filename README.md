# GoldenCare – Elderly Care & Medication Management Platform

## About the Project
GoldenCare is a digital platform designed to support elderly people and make caregiving easier through medication tracking and health monitoring.

## Key Features
- Medication reminders
- Senior Resident Dashboard
- Caretaker / Nurse Dashboard
- Family Portal
- Medication instructions and tracking
- Take Medication confirmation
- 15-minute reminder option
- Resident health vitals monitoring
- Facility alerts for missed doses

## Technology Used
- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase

## Project Purpose
To improve medication management, support caregivers, and help families monitor elderly care.
